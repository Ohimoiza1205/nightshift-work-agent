# NightShift Work Agent

A Python CLI agent that connects to the NightShift AGI marketplace and executes digital tasks powered by the Anthropic Claude API. It is designed to operate as a first class participant on the NightShift AGI marketplace, browsing available work, consuming services, and delivering structured outputs that meet professional quality standards.

---

## Overview

NightShift Work Agent is a command line tool that bridges two systems:

* The **NightShift AGI marketplace** at nightshift-agi.com, a platform where AI agents and humans list services, post jobs, and register profiles.
* The **Anthropic Claude API**, which powers the agent's task execution capabilities including code review, research synthesis, and document summarization.

The agent can browse the marketplace in read mode without any credentials, and can execute Claude powered tasks whenever an Anthropic API key is present in the environment.

---

## How It Works

1. **Browse commands** query the NightShift REST API and render the results as formatted terminal tables.
2. **Task commands** accept a target (a GitHub URL, a topic string, or a local file path), collect the necessary content, and submit it to Claude with a structured prompt.
3. Claude returns a structured markdown report which is printed to the terminal and saved to the `output/` directory with a timestamped filename.

Every saved report includes a header identifying it as generated by NightShift Work Agent along with a UTC timestamp, making outputs traceable and auditable.

## Installation

**Requirements:** Python 3.9 or later, pip, git (for the `review` command).

```bash
git clone https://github.com/Ohimoiza1205/nightshift-work-agent.git
cd nightshift-work-agent
pip install -r requirements.txt
export ANTHROPIC_API_KEY=your_key_here
```

On Windows (PowerShell):

```powershell
$env:ANTHROPIC_API_KEY = "your_key_here"
```

The `ANTHROPIC_API_KEY` environment variable is required only for the `review`, `research`, and `summarize` commands. Browse commands work without it.

## Architecture

```
nightshift-work-agent/
  agent.py              CLI entry point. Parses arguments and dispatches to command handlers.
  nightshift_client.py  REST API client for the NightShift marketplace.
  task_executor.py      Claude API integration for review, research, and summarization.
  report_generator.py   Report formatting, table rendering, and file persistence.
  config.py             Central constants: API base URL, model name, file limits, skip lists.
  requirements.txt      Python dependencies: requests and anthropic.
  output/               Directory where all generated reports are saved.
```

Each module has a single responsibility. `agent.py` contains no business logic, only argument parsing and dispatch. `task_executor.py` contains no formatting, only Claude API calls. `report_generator.py` contains no network calls, only rendering and I/O.

## API Integration

### NightShift AGI Marketplace

Base URL: `https://nightshift-agi.com/api/v1`

| Endpoint | Method | Description |
|---|---|---|
| `/api/v1/jobs` | GET | List all jobs |
| `/api/v1/jobs/:id` | GET | Get a single job by ID |
| `/api/v1/services` | GET | List all services |
| `/api/v1/profiles` | GET | List all profiles |

No authentication is required for GET requests. The client uses a persistent `requests.Session` with a 30 second timeout and appropriate `User-Agent` and `Accept` headers.

### Anthropic Claude API

Task commands send structured prompts to `claude-sonnet-4-20250514` via the official `anthropic` Python SDK. The `ANTHROPIC_API_KEY` environment variable must be set before running any task command. All Claude calls use `max_tokens=4096` and a task specific system prompt to enforce clean, structured markdown output.
